# PASOA UI Style Contract

This command is mandatory for every future UI change:

> **Use the PASOA brutalist design system for every surface: Admin, Landing, Student, Service Provider, and Guest. Do not use bento layouts, rounded cards, gradients, soft shadows, glassmorphism, pastel accent colors, or unrelated color tokens. Use only the 60/30/10 palette: 60% Biscotti `#E3C565`, 30% Cafe Noir `#4B3621`, and 10% Black `#000000`. Prefer square geometry, visible borders, hard-edged hierarchy, compact typography, icon-led navigation, and explicit states. Reuse shared primitives from `src/components/WireframeUI.tsx` and keep responsive behavior intact.**

## Required palette

- 60% Biscotti: `#E3C565`
- 30% Cafe Noir: `#4B3621`
- 10% Black: `#000000`

No new screen, component, or style may introduce a competing palette or return to bento styling.
